## Optional noise result

The completed NSTDB experiment uses record 118 at 300–420 s. `results/figures/f1_vs_noise.png` and `results/metrics/noise_robustness.csv` show F1 of 1.0000 (clean), 1.0000 (18 dB), 0.7288 (6 dB), and 0.5170 (0 dB). Fixed detector settings were reused across conditions. This is a narrow robustness check.

## Limitations

Only two core records and one lead were evaluated, so generalization is unknown. The record 118 streaming miss is a terminal edge effect: the last reference beat is only 25 samples before the end and falls inside the 0.5 s safety margin. Detection drops with heavy electrode-motion noise. The browser is a course demonstration, the `quality` field is only a sample-present indicator, and no clinical or medical-device claim is supported.
